# Changelog

## 2.0.2
- Sequencer: type the pattern Length (1–64); clicking past the end no longer lengthens a pattern.
- New UNDO (⌘Z), SAVE, RESET (stock pattern) and INIT (empty pattern) buttons.
- Always starts on pattern 1-1 in CHORD mode: Pop Bright, voicing F#4, PULSE 7 OFFBEAT, Synth Brass.
- A new version starts from the stock patterns (your old file is kept as chordially-before-build22.json).

## 2.0.1
- Menus and buttons no longer keep the keyboard: the Mac keys play right after choosing an instrument.
- The window takes the first click (PLAY never needs a second click).
- Donation note in SETUP; styled DMG installer.

## 2.0.0 — first public release
- One key plays a voice-led chord from 64 chord sets; KEY, VOICING, CHORD on/off, HOLD.
- Phrases: 8 styles × 8 variations (arpeggios, pulses, rhythms, strums), GATE, GATE RND, SWING, STRUM, OCTAVE.
- Chord sequencer: 64 patterns × up to 64 steps, tie / rest / per-step style, real-time REC, RANDOM and GENERATIVE.
- Built-in synth with 62 chord sounds (pads, strings, brass, keys, plucks, bells), ADSR, EG INT, FILTER, RESO, SUB, EQ, PAN.
- Audio Unit instrument and one AU insert effect; delay, reverb, master compressor.
- Roland S-1 / T-8 over USB: audio in, MIDI IN and SYNC per box, aggregate-device support.
- MIDI in / out, clock master or follow, MIDI learn on every knob, KeyStep 37 defaults.
- Six skins, full built-in help.
